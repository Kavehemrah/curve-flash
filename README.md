# Curve Flash

نرم‌افزار دسکتاپ PySide6 برای محاسبه فلش قوس از مختصات نقاط Excel.

## ورودی
- فایل XLS یا XLSX و انتخاب Sheet از داخل رابط برنامه
- ستون A: شماره نقطه
- ستون B: مختصات شمالی (Y)
- ستون C: مختصات شرقی (X)
- ردیف عنوان و ردیف‌های غیرعددی نادیده گرفته می‌شوند؛ حداقل ۱۹ نقطه لازم است.

## روش محاسبه فلش
برای هر بازه ۱۸ فاصله‌ای، فقط وتر بین نقطه ابتدا و انتها ساخته می‌شود و فاصله عمود نقطه وسط بازه از خط وتر، فلش قوس است. برای مثال در بازه نقاط ۱ تا ۱۹ فقط فاصله نقطه ۱۰ محاسبه می‌شود. بازه بعدی از نقطه ۱۹ تا ۳۷ خواهد بود؛ بنابراین ابتدا و انتهای بازه‌ها مشترک‌اند و نقاط داخلی دیگر محاسبه نمی‌شوند. علامت فلش نیز حفظ می‌شود. واحد نتیجه همان واحد مختصات است.

خروجی XLSX شامل کپی برگه ورودی با هایلایت نقاط بحرانی، برگه Flash Results و برگه Midpoint Flash است. فایل اصلی تغییر نمی‌کند.

## اجرا در PowerShell

