# Curve Flash

نرم‌افزار دسکتاپ PySide6 برای محاسبه فلش قوس از مختصات نقاط Excel.

## ورودی
- فایل XLS یا XLSX و انتخاب Sheet از داخل رابط برنامه
- ستون A: شماره نقطه
- ستون B: مختصات شمالی (Y)
- ستون C: مختصات شرقی (X)
- ردیف عنوان و ردیف‌های غیرعددی نادیده گرفته می‌شوند؛ حداقل ۱۹ نقطه لازم است.

## محاسبه نسخه اولیه
وتر از نقطه i تا نقطه i+18 تشکیل می‌شود و فاصله عمود نقاط میانی نسبت به خط وتر محاسبه می‌شود. بیشینه بر اساس قدر مطلق انتخاب می‌شود و علامت فاصله نیز نگهداری می‌شود. برای ۲۷۸ نقطه، ۲۶۰ وتر و ۴۴۲۰ فاصله محاسبه خواهد شد. واحد نتیجه همان واحد مختصات است.

خروجی XLSX شامل کپی برگه ورودی با هایلایت نقاط بحرانی، برگه Flash Results و برگه Point Deviations است. فایل اصلی تغییر نمی‌کند.
