# Curve Flash

نرم‌افزار دسکتاپ PySide6 برای محاسبه فلش قوس از مختصات نقاط Excel.

## ورودی
- فایل XLS یا XLSX و انتخاب Sheet از داخل رابط برنامه
- ستون A: شماره نقطه
- ستون B: مختصات شمالی (Y)
- ستون C: مختصات شرقی (X)
- ردیف عنوان و ردیف‌های غیرعددی نادیده گرفته می‌شوند؛ حداقل ۱۹ نقطه لازم است.

## روش محاسبه فلش
برای هر وتر با طول ۱۸ فاصله، فقط فاصله عمود نقطه دقیقاً وسط همان وتر از خط وتر محاسبه می‌شود؛ هیچ‌یک از نقاط داخلی دیگر بررسی نمی‌شوند. پنجره محاسبه هر بار فقط یک نقطه جلو می‌رود: وتر ۱ تا ۱۹ فقط نقطه ۱۰ را می‌سنجد، وتر ۲ تا ۲۰ فقط نقطه ۱۱ را، وتر ۳ تا ۲۱ فقط نقطه ۱۲ را و به همین ترتیب تا آخرین وتر ممکن. بنابراین اگر N نقطه معتبر داشته باشیم، N−۱۸ اندازه فلش محاسبه می‌شود. علامت فلش نیز حفظ می‌شود. واحد نتیجه همان واحد مختصات است.

خروجی XLSX شامل کپی برگه ورودی با هایلایت نقاط بحرانی، برگه Flash Results و برگه Midpoint Flash است. فایل اصلی تغییر نمی‌کند.
